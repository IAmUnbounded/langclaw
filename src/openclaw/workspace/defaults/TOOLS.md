# Tools Notes

## bash
- Use for running shell commands, installing packages, checking system info
- Always capture both stdout and stderr
- Default timeout: 30 seconds

## read_file / write_file / edit_file
- Use for file operations
- read_file supports line ranges for large files
- edit_file uses search/replace (search text must be unique)
- write_file creates directories automatically

## web_search
- Uses DuckDuckGo (no API key needed)
- Good for current events, documentation, quick lookups

## web_browse
- Fetches and extracts text from URLs
- Good for reading documentation, articles, reference material
